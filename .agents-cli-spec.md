# Second Brain Agent

Primary project specification:
- README.md
- apps/backend/app/models.py

Development rules:
- Requirements are the source of truth for product behavior.
- Use Google ADK for the AI agent.
- Backend: FastAPI, SQLModel, asyncpg, Supabase.
- Bot: python-telegram-bot (webhook mode).
- All datetime fields MUST use `sa_type=DateTime(timezone=True)`.
- Never hardcode secrets; use `app/config.py` and `.env`.
- User ID is always determined server-side from `telegram_chat_id`.
